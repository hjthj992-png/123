# Linocut Express

21-секундный фильм в стиле линогравюры: красный паровоз в зимних горах.
Всё сделано кодом: ни одной картинки, модели или видео-ассета.

## Как устроено

| Слой | Файл | Что делает |
|---|---|---|
| Сцена | `scene.js` | Three.js: рельеф с шумом, ~3600 ёлок (instancing), гранёные горы, рельсы по сплайну, паровоз и вагоны из примитивов, работающие дышла, тоннель |
| Стиль «гравюры» | `scene.js` → `LINO_FRAG` | Свой шейдер: плоский свет с порогами → сплошная тушь / штриховка «стамеской» / бумага; снег на верхних гранях, иней на краске, царапины на снегу |
| Пост-обработка | `scene.js` → `postMat` | Контуры (лапласиан 1/z + разрывы нормалей), небо с резными штрихами и звёздами, зерно бумаги, виньетка |
| Дым и снег | `scene.js` | Детерминированные частицы: клубы + спирали из трубы, 32 000 снежинок в шейдере |
| Камера | `SHOTS` | 5 планов: общий → паровоз крупно → вагоны мимо камеры → погоня → тоннель |
| Рендер | `render.mjs` | Headless Chromium (Playwright) рендерит кадр за кадром → ffmpeg |
| Звук | `audio.mjs` | Синтез: пыхтение пара, стук колёс на стыках, гудок с эхом, ветер, дрон |
| Сборка | `finish.sh` | 1080p 16:9 + вертикальная 9:16 версия с подписью |

## Запуск

```bash
npm install
npx serve .                      # открыть index.html — превью в реальном времени
node render.mjs --stills 2,6,10  # контрольные кадры в out/
node render.mjs                  # полный рендер 2560x1440@30 → out/film_raw.mp4
node audio.mjs                   # out/sound.wav
bash finish.sh                   # out/linocut_express_16x9.mp4 и _9x16.mp4
```
